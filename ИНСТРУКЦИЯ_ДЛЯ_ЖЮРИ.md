# Инструкция по запуску проекта Argus AI (Для жюри)

Добро пожаловать! В этой инструкции кратко описано, как запустить наш проект с нуля локально на вашем компьютере для проверки работоспособности (включая AI-аналитику нарушений, LiveKit трансляцию и дашборд).

## 📋 Требования (Что должно быть установлено)
Для успешного запуска у вас должны быть установлены следующие инструменты:
1. **Docker Desktop** (Обязательно, должен быть запущен)
2. **Go** (Для запуска воркера обработки событий)
3. **Python 3** (Для генерации тестовой ссылки на экзамен)

---

## 🚀 Шаги для запуска

### Шаг 1. Запуск инфраструктуры и основных сервисов
Откройте терминал в корневой папке проекта (`Case-3`) и запустите Docker Compose. Проще всего это сделать через готовый скрипт:

**Для Windows:**
Дважды кликните по файлу `start.bat` или выполните в терминале:
```bash
./start.bat
```
*(При первом запуске это займет некоторое время, так как будут скачиваться образы БД, собираться Backend и Frontend. Дождитесь, пока в консоли не появится сообщение, что сервисы запущены).*

### Шаг 2. Запуск фонового обработчика (Worker)
Worker отвечает за обработку событий (видение телефона, нескольких людей, звука и т.д.) и запись их в базу данных. 
Не закрывая терминал из Шага 1, откройте **новое окно терминала** (PowerShell) в корне проекта и выполните:
```powershell
./run_worker.ps1
```
Оставьте этот терминал открытым, чтобы воркер продолжал работать в фоне.

### Шаг 3. Генерация ссылки на экзамен
Чтобы зайти в качестве студента и проверить, как работает камера и AI-прокторинг, сгенерируйте тестовую ссылку. 
Откройте **третье окно терминала** в корне проекта и выполните:
```bash
python generate_test_link.py
```
В консоли появится длинная ссылка (начинается на `http://localhost:3000/exam.html?...`). 

### Шаг 4. Проверка работы
1. **Студент:** Скопируйте ссылку, полученную в Шаге 3, и откройте её в браузере (лучше в режиме **Инкогнито**). Согласитесь с правилами, пройдите проверку камеры и начните экзамен.
2. **Проктор (Дашборд):** Откройте в новой вкладке `http://localhost:3000`. Там вы увидите дашборд администратора/проктора. 
   - Зайдите в активную сессию студента.
   - Вы увидите прямую трансляцию с камеры студента.
   - Попробуйте нарушить правила (возьмите в руки телефон или позовите второго человека в кадр).
   - В течение пары секунд нарушение отобразится в дашборде.

## 💡 Возможные проблемы
- **Не запускается база (Postgres/ClickHouse):** Убедитесь, что порты `5435`, `8123`, `9000` свободны на вашем ПК.
- **"Сілтеме жарамсыз" или SDK не грузится:** Скорее всего, вы скопировали ссылку из терминала не полностью, либо пытаетесь открыть её напрямую в терминале, а не в браузере. Обязательно вставляйте всю ссылку целиком в адресную строку Chrome/Edge.
